# 🐙 GitHub Guide for SIH Teams

## Recommended repository structure
```text
project/
├── README.md
├── docs/
├── src/
├── tests/
├── assets/
├── .env.example
├── CONTRIBUTING.md
└── LICENSE
```

## Before pushing
- Never commit API keys or passwords.
- Add `.env` to `.gitignore`.
- Write setup instructions.
- Add screenshots/GIFs.
- Keep commit messages meaningful.

## Demo-ready README
Your README should quickly answer:
1. What is this?
2. Who is it for?
3. What problem does it solve?
4. How does it work?
5. Tech stack?
6. How do I run it?
7. What is implemented?
8. What is next?
