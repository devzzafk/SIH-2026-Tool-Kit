# ✅ SIH Submission Checklist

Always cross-check the latest official instructions.

## Problem
- [ ] Correct problem statement
- [ ] Problem clearly understood
- [ ] User and impact defined

## Solution
- [ ] Clear solution statement
- [ ] Innovation explained
- [ ] MVP defined
- [ ] Technical architecture ready

## Prototype
- [ ] Core flow works
- [ ] Demo data prepared
- [ ] Screenshots/video backup
- [ ] Deployment tested

## Pitch
- [ ] Official template followed
- [ ] Slide limit checked
- [ ] Text is readable
- [ ] Team roles clear
- [ ] Judge questions rehearsed

## Final
- [ ] Names and IDs checked
- [ ] Links tested
- [ ] Files open correctly
- [ ] Submission deadline/timezone verified
