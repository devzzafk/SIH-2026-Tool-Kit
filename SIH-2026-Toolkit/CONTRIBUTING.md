# Contributing 🤝

Thanks for helping make this toolkit better for students!

## Good contributions
- Useful, working resources
- Original checklists and frameworks
- Clear tutorials
- Prompt improvements
- Templates
- Bug fixes
- Accessibility and documentation improvements

## Before opening a PR
- Check that the resource is not already listed.
- Prefer official sources for rules and deadlines.
- Credit external material.
- Don't add pirated, copyrighted, or private material.
- Keep instructions beginner-friendly.

## Pull request format
Please explain:
1. What you changed
2. Why it helps SIH participants
3. Any source links or credits

Small, focused PRs are welcome. ❤️
