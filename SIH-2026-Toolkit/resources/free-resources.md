# 🧰 Free / Student-Friendly Resources

> Availability, quotas, and student benefits change. Verify current terms before building around any service.

## Categories to explore
- Open-source AI/ML libraries
- Public government datasets
- Research datasets
- GitHub open-source projects
- Student cloud credits
- Free-tier databases
- Static hosting
- Open mapping platforms
- Design/prototyping tools

## Evaluation checklist
Before choosing a service, check:
- Free-tier limits
- API rate limits
- Commercial-use restrictions
- Data privacy
- Regional availability
- Whether a card is required
- Whether the service is suitable for a hackathon demo
