# 📋 Problem Statements

Use this folder to organize problem statements you are researching.

## Recommended format
For each problem statement, record:
- ID
- Official title
- Theme/category
- Organization
- Short problem summary
- Target users
- Key constraints
- Official source
- Date verified

**Important:** Don't copy or redistribute restricted material. For current IDs, titles, rules, and deadlines, use the latest official SIH communication.
