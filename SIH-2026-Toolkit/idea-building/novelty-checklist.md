# 💡 Novelty Checklist

Novelty does **not** mean adding AI just because AI is popular.

Ask:

- [ ] Is there a genuinely different workflow?
- [ ] Does the solution solve an overlooked user pain point?
- [ ] Is there a better data or feedback loop?
- [ ] Does it work in a difficult real-world environment?
- [ ] Does it improve accessibility or inclusion?
- [ ] Is there a meaningful technical improvement?
- [ ] Can the difference be demonstrated?

### Red flags
- “We added AI” with no reason for AI.
- Copying an existing app with a new UI.
- Features that cannot be demonstrated.
- Claims of novelty without researching existing solutions.
