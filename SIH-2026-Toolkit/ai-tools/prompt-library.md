# 🤖 SIH AI Prompt Library

Replace `[PROBLEM STATEMENT]` with your actual problem statement.

## 1. Understand the problem
```text
Act as a hackathon mentor. Analyze this problem statement:
[PROBLEM STATEMENT]

Explain:
1. The core problem in simple language
2. Who is affected
3. Root causes
4. Current pain points
5. Constraints implied by the statement
6. What a successful solution should achieve
Do not invent facts that aren't supported by the statement.
```

## 2. Stakeholder mapping
```text
Create a stakeholder map for:
[PROBLEM STATEMENT]

For each stakeholder, give their goals, pain points, access to technology,
and how our solution could interact with them.
```

## 3. Existing-solution research
```text
For this problem:
[PROBLEM STATEMENT]

List categories of existing solutions, likely competitors/projects,
and what gaps a new solution should investigate. Clearly separate
known facts from hypotheses that need verification.
```

## 4. Innovation gap
```text
Based on:
[PROBLEM STATEMENT]

Generate 10 possible innovation directions. For each, score:
- User value /10
- Technical feasibility /10
- Novelty potential /10
- Implementation risk /10

Then recommend the strongest 3 directions and explain why.
```

## 5. MVP
```text
Design an MVP for this SIH solution:
[IDEA]

Give:
- Must-have features
- Nice-to-have features
- Features to avoid for MVP
- User flow
- Demo flow
- Success metrics
```

## 6. Architecture
```text
Act as a senior software architect. Design a practical architecture for:
[IDEA]

Include frontend, backend, database, authentication, AI/ML components,
external APIs, data flow, deployment, security considerations, and a
simple text-based architecture diagram. Prefer free/student-friendly tools.
```

## 7. PPT
```text
Create content for a maximum 6-slide SIH-style pitch deck for:
[IDEA]

For each slide provide concise presentation-ready bullets covering:
problem, solution, novelty, technical approach, feasibility/impact,
and implementation/roadmap. Do not overload slides with text.
```

## 8. Judge questions
```text
Act as a strict hackathon judge evaluating:
[IDEA]

Ask 20 difficult questions across novelty, feasibility, scalability,
security, cost, data, AI necessity, deployment, users, and business/social impact.
After the questions, provide what a strong answer should address for each.
```

## 9. Demo script
```text
Write a 3-minute live demo script for:
[PRODUCT]

Structure it as: problem → user → action → product response → key innovation → impact.
Keep it realistic and avoid claiming features that are not implemented.
```
